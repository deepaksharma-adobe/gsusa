# Footer

This is the authoring document for the site footer fragment. Author it at the
path `/footer` (or set a `footer` metadata key on a page to point elsewhere).
Each section below is separated by `---` and tagged with a **Section Metadata**
block whose **Style** value becomes the section CSS class the footer block reads.
